# Eventora - Event Booking

Single-file event booking website using HTML, CSS and JavaScript.

## Run
Open `event-booking.html` in a browser.

## Features
- Event search and category filter
- Event details
- Ticket booking
- Total price calculation
- My Bookings section
- Cancel booking
- LocalStorage persistence
- Responsive design

## Deployment
This single HTML file can be deployed using GitHub Pages, Netlify or Vercel.

Note: This version does not use MySQL. Browser JavaScript cannot safely connect directly to MySQL. A Node.js/Express backend is required for real MySQL storage.
